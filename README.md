# Markdown Lookup MCP Server

A production-ready Model Context Protocol (MCP) server that answers natural language questions by searching curated Markdown documentation. The backend exposes a clean HTTP API via FastAPI, runs entirely on Ubuntu with open-source dependencies, and ships with a sample client for quick integration testing.

## Features

- Deterministic TF-IDF retrieval over large Markdown documentation.
- Zero recurring costs — no paid APIs or hosted vector databases.
- FastAPI-powered backend with autogenerated OpenAPI documentation.
- Environment-driven configuration for deployment flexibility.
- Sample client script demonstrating how to consume the API.

## Tech Stack

| Layer | Technology | Purpose |
| --- | --- | --- |
| Runtime | Python 3.11 | Primary language and runtime |
| Web Framework | FastAPI | HTTP routing, validation, and OpenAPI generation |
| Server | Uvicorn | ASGI server that runs the FastAPI app |
| Data Processing | Custom TF-IDF implementation | Lightweight vector scoring over Markdown chunks |
| HTTP Client (sample) | Requests | Demonstrates how to call the API from Python |

Additional detail is available in [`docs/TECH_STACK.md`](docs/TECH_STACK.md).

## Architecture

1. **FastAPI Layer** — Accepts HTTP requests, validates payloads with Pydantic models, and returns JSON responses.
2. **Query Service** — Enforces request limits, orchestrates the retrieval pipeline, and structures responses.
3. **Knowledge Base** — Loads the Markdown file at startup, chunks the content, and computes TF-IDF vectors for cosine similarity search.
4. **Storage** — Markdown resides on disk; no external databases or queues are required.

## Getting Started

### Prerequisites

- Ubuntu 22.04 LTS or later
- Python 3.11+
- `pip`

All Python dependencies are listed in [`requirements.txt`](requirements.txt).

### Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### Run the Server

```bash
python -m server.main
```

The service listens on `http://0.0.0.0:8000` by default and loads the bundled knowledge base at `server/data/knowledge_base.md`.

### Explore the API

- Interactive documentation: [http://localhost:8000/docs](http://localhost:8000/docs)
- OpenAPI schema: [http://localhost:8000/openapi.json](http://localhost:8000/openapi.json)

### Sample Client

```bash
python sample/run_sample.py
```

The script reads `sample/test_question.txt`, sends it to the server, and prints the JSON response.

## Configuration

Environment variables provide fine-grained control without code changes:

- `MCP_SERVER_HOST` — Interface to bind (default: `0.0.0.0`).
- `MCP_SERVER_PORT` — Port to bind (default: `8000`).
- `KNOWLEDGE_BASE_PATH` — Override path to the Markdown file.
- `DEFAULT_TOP_K` — Default number of excerpts returned (default: `3`).
- `MAX_TOP_K` — Maximum number of excerpts returned per query (default: `8`).

## API Reference

### `POST /query`

Request body:

```json
{
  "question": "string",
  "limit": 3
}
```

- `question` *(required)* — Natural language question.
- `limit` *(optional)* — Maximum number of relevant excerpts (1-20). Defaults to the server configuration.

Response body:

```json
{
  "question": "...",
  "matches": [
    {
      "excerpt": "...",
      "relevance": 0.87,
      "index": 5
    }
  ],
  "source": "/absolute/path/to/knowledge_base.md"
}
```

### `GET /healthz`

Returns `{ "status": "ok" }` when the service is operational.

## Running on Ubuntu

Because the project uses only open-source dependencies, there are no recurring licensing costs. A minimal production deployment on Ubuntu looks like:

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-venv
python3 -m venv /opt/mcp/.venv
source /opt/mcp/.venv/bin/activate
pip install -r requirements.txt
uvicorn server.main:app --host 0.0.0.0 --port 8080 --workers 2
```

Ensure the Markdown knowledge base is present and set `KNOWLEDGE_BASE_PATH` if you store it elsewhere.

## Project Structure

```
server/
  app.py               # FastAPI application factory
  config.py            # Environment-driven settings
  data/knowledge_base.md
                       # Markdown knowledge base used for lookups
  knowledge_base.py    # Markdown chunking and TF-IDF search implementation
  main.py              # Entrypoint exposing `main()` and the ASGI app
  models.py            # Pydantic request/response schemas
  service.py           # Query orchestration layer
sample/
  run_sample.py        # Client script that calls the MCP server
  test_question.txt    # Example query text
```

## Sample Workflow

2. Execute `python sample/run_sample.py` to send the example question.
3. Inspect the JSON response printed by the script.
